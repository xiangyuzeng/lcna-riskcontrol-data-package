## 3. 主要发现

1. **共用区号规则被扩，引用它的策略跟着变了**：`rule_CrVrUuDk1hHJ` 2026-10-09 01:55:30 UTC 从 15 个区号扩到 21 个（规则名已同步改）；在线的 WvNG、bYXa 与预上线的 MZQk 随之扩大，三条的策略名仍写 15 个，改规则也没让在线的退回预上线；eoHQ、E1HJ 是之后新建的，一开始就是 21 个（`results/dr031_code_versions.csv`、`results/dr034_timeline.csv`；DR-034）。
2. **bYXa 的条件在 15 个区号上全部生效，剩下的放行只来自美国 IP 与号码本国 IP**：纽约日 10-02 起 15 个区号的短信请求中，两个 IP 条件都成立的占 54.6%；上线后仍放行的是美国 IP 111 次、本国 IP 64 次（`results/dr031_ip_split_share.csv`、`results/dr031_after_switch_by_cc.csv`；DR-031）。
3. **43Na 上线后第一个 24 小时内，它的条件成立的请求就大幅减少；被拒号码约六成会再试**：上线后被它唯一拦下的号码 1,976 个，60.5% 再次请求，距下次请求中位数 0.92 分钟；tk10 与 E1 逐格一致（101 格，0 不一致）（`results/dr030_*.csv`；DR-030，计数分解，非因果）。
4. **MySQL 源库与 Doris 按 UTC 日汇总一致**：UTC 日 09-13…10-08 短信 PASS 26/26 天与 Doris 完全相同，总量最多差 1（`results/dr036a_utc_daily_vs_doris.csv`；DR-036）。
5. **攻击仍在**：k=5 下纽约日 09-03…10-09 每天都是攻击日（37/37）；非 +1 占短信 PASS 在 10-08、10-09 降到 27.1%、19.1%（`results/dr010_attack_rule.csv`、`results/bridge_daily_series.csv`）。
6. **过滤条件在日志里生效**：按条件重算与引擎值一致 99.7% / 94.8%，不按条件只有 11.2% / 52.7%（`results/p8_counter_recheck_summary.csv`）；组合维度特征仍 100% `DIMENSION_EMPTY`（DR-003）。
7. **eoHQ 的一条规则名实不符**：`rule_sih7inbv75df` 名称「大于 2」，条件是 `< 2`（10-10 01:17 UTC 改），命中的是每个号码当小时的第一次请求（`results/config_rule.csv`、`results/dr034_daily_hits.csv`；`05_开放探索_20261009.md` §2）。
8. **「IP 省份不是 NY/NJ 就拒」在正常时期也会拦掉 15 个区号几乎全部请求**：攻击前三个月（纽约日 06-01…08-31）15 个区号的短信请求 5,958/6,012 不在 NY/NJ（含 1,727 次当时放行的）；攻击期 20 天来自 NY/NJ 的约 1.8%，不是「不到 1%」（`results/dr032_province_split.csv`、`results/dr036e_nynj_share.csv`；DR-032、DR-036）。
