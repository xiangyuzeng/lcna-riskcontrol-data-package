## 2. 口径

照 `toolkit/README_patrol24.md`：

- **窗口**：截止 T = 当天纽约时间 21:00，起点 = T 往前整 24 小时（86,400 秒，夏令时切换那天也一样），转成 UTC 写死在语句里。
- **① 短信请求总量**：`scene_id='LKUS_push'` 且 `$.para.email` 为空。
- **② 短信请求pass量**：① 里 `result='PASS'`（最终返回给调用方的结果）。
- **③ 非美国区号且非中国区号的 pass 量**：② 里区号是 1–4 位数字、且不是 1 和 86。
- **④ 21 个区号的 pass 量**：② 里区号在 `toolkit/codes_21.txt`。

每条回复带窗口、分表范围、分表数与编号和、重复读行数，`collect` 逐项核对；按区号的四条再对一次 ③、④。
